# builder-skills

Short name for [@waynesutton/builder-skills](https://www.npmjs.com/package/@waynesutton/builder-skills), so you can type less.

```bash
npx builder-skills
```

That opens the picker. Every command from the main package works the same way: `npx builder-skills add --all`, `npx builder-skills list`, `npx builder-skills update`.

Docs and source: https://github.com/waynesutton/builder-skills
