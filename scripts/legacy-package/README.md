# @waynesutton/convex-skills (renamed)

This package is now [@waynesutton/builder-skills](https://www.npmjs.com/package/@waynesutton/builder-skills).

```bash
npx builder-skills
```

The Convex skills that used to live here are now official Convex skills:

```bash
npx skills add convex/agent-skills
```

Or tell your agent: "Read https://www.convex.dev/agent-setup.md and follow it."

The full old to new map is in [MIGRATING.md](https://github.com/waynesutton/builder-skills/blob/main/MIGRATING.md).
